## 内容链路

使用临时、唯一 slug 的文章验证真实开发监听器和本地 R2：

1. 新文章自动出现在 `/api/posts`，不执行 Astro 构建。
2. 直接访问新文章 URL，响应包含完整正文、标题、canonical，且无模板 noindex。
3. RSS 与 sitemap 自动包含文章。
4. 修改标题后列表及详情均更新。
5. 写入非法日期时，已发布内容保持可读。
6. 改为草稿后列表移除，HTML 和 Markdown 直读均返回 404。
7. 验证前后 `dist/index.html` 的修改时间相同。
8. 临时文章被清理，索引恢复。

独立测试另覆盖：CRLF frontmatter、非法 slug、空正文、未来日期、危险资源链接、Markdown 活跃 HTML 过滤、表格/代码保留、重复标题锚点，以及详情同时校验索引和正文发布状态。

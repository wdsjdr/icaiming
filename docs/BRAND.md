# IC Aiming · 品牌与界面规范 v0.2.1

英文主名为 **IC Aiming**，保留 IC 与 Aiming 之间的空格。IC 同时指 Ice Cold 和 “I see”；Aiming 指瞄准，也是名字的一部分。当前辅助文案为「冷静观察，持续瞄准。」以及 “Stay cool. See clearly. Keep aiming.”。

## 标识

- A 为上方聚焦轮廓，W 以对称折面承接下方；两者用实心几何路径构造，中间保留间隙，避免缩小后描边交叠。
- 完整标识：外侧开口环呼应 C，右侧定位短线呼应 I。环和短线统一为 6 个设计单位的粗细，主体更厚，形成主次。用于首页、关于页和大幅展示，推荐至少 64px。
- 紧凑标识：保留 A/W 核心、收紧画布，用于 16–48px。导航使用 34px，页脚 28px；favicon 使用同一核心的有底色版本。
- 网站组件：`src/components/ui/BrandMark.astro`，默认 `variant="full"`；小尺寸使用 `variant="compact"`。使用 `currentColor` 随站点主题变化。
- 独立文件：内容仓库 `assets/brand/mark.svg`、`mark-compact.svg`、`wordmark.svg`。SVG 默认通过系统色彩偏好适配明暗；嵌入固定背景时应显式指定相应前景色。
- favicon：`public/favicon.svg`，深色底、浅色实心核心，增加内边距。
- 四周额外留白推荐不小于图标宽度的 1/6；标识保持水平，不拉伸、不添加阴影和倾斜。
- 横版组合采用 IC 常规字重、Aiming 稍重字重，字距为字号的 -0.04em。独立 SVG 字标保留可编辑文字，正式印刷交付时再转轮廓。
- 原素材 `资源/Logo.svg` 留作来源参考；平台图标来自同目录，对应内容仓库 `assets/icons/`。

### 本地预览

运行 `pnpm dev` 后打开 **http://localhost:4321/brand**，查看完整标识的明暗效果、16/24/32/48px 紧凑标识与横版组合，也可下载 SVG。该页为 noindex 的设计预览页。

## 视觉变量

默认：冰白 `#f4f7f7`、石墨 `#162d35`、冰蓝强调 `#14617c`；暗色：深蓝灰 `#10191e`、浅色正文 `#e1e9ec`、浅冰蓝 `#95d2e7`。

按钮文字与背景使用独立变量 `--button-ink` 与 `--accent`。全站共享尺寸、边框、圆角、间距；博客在默认亮色下使用纸色背景和衬线标题，好玩区使用更温暖的局部强调。

正文采用本地系统字体栈，中文回退到苹方或微软雅黑；长文标题使用系统衬线，数据和标注使用系统等宽字体。页面不请求第三方字体。

## 主题和交互

`data-mode` 表示最终亮暗；`colorMode` 偏好为 light/dark/system。`data-theme` 为 default/terminal/newspaper。`data-section` 决定页面排版气质。

URL `?theme=terminal&mode=dark` 只临时预览，不写入存储。用户手动选择后退出预览。动效偏好与系统减少动画设置共同决定 `data-motion`；系统设置优先。品牌页采用短暂入场，实验由用户操作驱动。

## 开屏动画

首页每个会话首次进入播放约 6.4 秒：
1. 0–1.0s：纯黑中原子线条（亮芯 + 柔光外鞘）由远及近描出，镜头微俯视推近。
2. 1.0–3.0s：核子簇脉动发光，三电子带拖尾沿倾斜轨道绕核；左上角 HUD 显示阶段，左下坐标跳动。
3. 3.0–3.5s：急刹，轨道摆平为平面原子，坐标归零，背景点阵浮现。
4. 3.5–4.2s：镜头稍退，绕 Y 轴翻转；90° 处冰蓝光爆 + 两道冲击环，露出完整标识，随后一道高光扫过。
5. 4.2–5.6s：标识上移，瞄准框收拢锁定，下方逐段浮现标语「Stay cool. See clearly. *Keep aiming.*」、细分隔线和「冷静观察 · 持续瞄准」。
6. 5.6–6.4s：标语上浮淡出，镜头穿过标识中心，星点拉成光线，背景由黑过渡到当前主题 `--bg`，标识色过渡为 `--accent`。

光效统一用冰蓝 `#95d2e7`；标语英文用 `--font-display`，中文副标用等宽字体。标语、瞄准框按 3D 标识的投影位置定位，各种宽高比下都贴在标识下方。

可随时用「跳过」或 Esc 结束；`?intro=1` 重播，`?intro=0` 关闭。减少动画或关闭动画偏好时不播放；内存小于 4 GB 或无 WebGL2 时改为约 2.8 秒 CSS 简版（同样包含标语）；手机和低核数设备减少星点并关闭电子拖尾。
